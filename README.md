# Калькулятор векторов на C++

## Описание проекта

Программа представляет собой калькулятор двумерных векторов. Она позволяет выполнять математические операции над двумя векторами, координаты которых вводятся пользователем.

## Возможности программы

Программа поддерживает следующие операции:

- **Сложение (+)** — сложение соответствующих координат двух векторов.
- **Вычитание (-)** — вычитание соответствующих координат второго вектора из первого.
- **Умножение (*)** — покоординатное умножение двух векторов.
- **Скалярное произведение (**)** — вычисление суммы произведений соответствующих координат двух векторов.

## Структура программы

- `enum OPER` — перечисление доступных математических операций.
- `vec()` — вывод координат вектора.
- `vect_plus()` — сложение векторов.
- `vect_minus()` — вычитание векторов.
- `vect_multiny()` — покоординатное умножение векторов.
- `vect_sclar()` — вычисление скалярного произведения.
- `main()` — основной алгоритм программы, отвечающий за ввод данных, определение операции и вывод результата.

## Пример работы

**Ввод:**
```text
Введите вектора a=(x;y) b=(x;y): a=(1;2) b=(3;4)
Введите операцию (+, -, *, **): +
```

**Результат:**
```text
c=(4;6)
```
